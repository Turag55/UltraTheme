## Image Background Remover Tool

This repository also includes a free online image background remover tool.

### Features

- **100% Private**: All processing happens in your browser - images never leave your device
- **AI-Powered**: Uses advanced machine learning for accurate background removal
- **Fast & Free**: Get results in seconds with no sign-up required
- **Works Everywhere**: Compatible with any modern browser on desktop, tablet, or mobile

### Usage

1. Open `index.html` in a web browser (or host it on a web server)
2. Drag & drop an image or click "Choose File" to upload
3. Wait for the AI to process your image
4. Download the result as a PNG with transparent background

### Supported Formats

- JPG/JPEG
- PNG
- WebP

### Technology

Built using the [@imgly/background-removal](https://github.com/imgly/background-removal-js) library, which provides client-side AI-powered background removal.
